Privacy Policy

So You Don't Have To Studio · last updated 2 November 2026

Who uses this tool

So You Don't Have To Studio is used only by the owner of the YouTube channel @SoYouDontHaveToTV to manage that channel. It is not a public service.

YouTube API Services

The tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What data is accessed

  • The owner's channel: videos, playlists, comments on the channel's videos, and the channel's YouTube Analytics reports.
  • Public statistics of public YouTube videos and channels (titles, view, like and comment counts) to find topics viewers care about.

How data is used and stored

Data is used only to publish the channel's videos, answer and moderate comments, and improve future videos. It is stored only on the owner's computer. It is never sold, shared with third parties, or used for advertising. Stored YouTube data is deleted or refreshed within 30 days. Comment text is kept only until it has been answered or moderated.

Cookies

This website and the tool do not use cookies or tracking.

Revoking access

Access can be revoked at any time at Google security settings. After that, stored data is deleted.
